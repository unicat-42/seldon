## 1. Главное

Блок войн спущен с годового шага на месячный: строка «страна × месяц» → вероятность того, что
в ближайшие 3, 6 или 12 месяцев начнётся (или продолжится) государственная война
`state_war25`. Всё проверено вслепую на 1996–2025 годах с честным лагом данных.

| Что проверяли | Результат |
| --- | --- |
| Месячный эталон `pitf` (история + режим + смертность + население) | AUC начала войны 0,871 / 0,867 / 0,864 на 3 / 6 / 12 месяцах; на тихих ≥ 5 лет — 0,785 / 0,778 / 0,787 |
| Предвестники «дым до огня» поверх эталона (`smoke_nb`) | мир: +0,012 [+0,005; +0,021] на 3 и 6 месяцах, +0,002 на 12; тихие ≥ 5 лет: +0,029 [+0,010; +0,047] на 3 месяцах; постсоветские и эпоха после 2014 — ноль |
| Тот же дым против «сухого» эталона, из которого убраны субпороговые погибшие | +0,040 [+0,025; +0,054] на мире, +0,056 на тихих ≥ 5 лет: дым работает, но большая его часть уже сидела в эталоне |
| Живые стычки государств вместо `MID` в диадной модели | −0,009 [−0,045; +0,026] — без разницы; после 2014 года тоже (−0,001) |
| Раздельные модели соседей и далёких держав | хуже: −0,050 [−0,099; −0,001]; знак соотношения сил у соседей исправился, но событий на две модели не хватает |
| Калибровка внешнего канала `p_ext` | завышение риска страны упало с +19 % до +6…7 % при том же AUC (+0,021 к `pitf`) |
| Сравнение с conflictforecast на их целевой | 3 месяца: мы 0,930, они 0,934 (с текстами новостей); на тихих ≥ 5 лет — 0,798 против 0,798 |
| Сравнение на нашей целевой | мы 0,907, они 0,858 (+0,049 [+0,022; +0,072]) — но их модель предсказывает другое событие |

AUC (area under ROC curve) — доля пар «война началась / не началась», которые модель
упорядочила правильно: 0,5 — монетка, 1 — идеально. В квадратных скобках — 95 % интервал
(блочный бутстрэп по годам, 500 реплик). `calib` — средняя предсказанная вероятность,
делённая на фактическую частоту: 1 — в среднем не врёт, больше 1 — завышает риск.

Коротко по смыслу. Месячная модель работает и на коротком горизонте честно лучше годовой
постановки. Но три правки диадного канала, на которые был расчёт, прироста не дали: помогла
только калибровка. Украина-2014 по-прежнему не видна ни одному каналу.

## 2. Разведка данных

### 2.1. UCDP Candidate Events

Candidate Events — оперативный набор UCDP в том же формате, что годовой GED, но
предварительный. Скачивается скриптом по прямой ссылке (`download ucdp_candidate`).

- Месячный файл за месяц m выкладывается **20-го числа месяца m+1**. Проверено по датам
  файлов на сервере: январь 2026 — 20.02.2026, сентябрь 2026 — 20.10.2026; так же в 2020,
  2021, 2023, 2025 годах (19–24 число). Файла за октябрь 2026 на 13.11.2026 ещё нет.
- Раз в квартал выходит накопленный файл с начала года. Подключён `GEDEvent_v26_01_26_09.csv`
  (январь–сентябрь 2026, 16 633 события) как продолжение GED 26.1, который кончается
  декабрём 2025.
- Лаг в `core/temporal.py`: `ucdp_events = 1` месяц. На строке месяца m все признаки считаются
  по событиям не позже m − 1.

Чем предварительные данные отличаются от выверенных — проверено на 2025 годе (накопленный
Candidate за 2025, выложенный 20.01.2026, против GED 26.1):

| | Candidate 2025 | GED 26.1, 2025 год |
| --- | --- | --- |
| Событий | 28 396 | 25 770 |
| Погибших, все типы насилия | 181 331 | 245 464 |
| Погибших в государственных конфликтах | 146 356 | 153 782 |
| Страна-месяцев с войной (≥ 25 погибших) | 234 | 227 (совпали 215) |

Флаг «месяц войны» совпадает в 94,9 % страна-месяцев, где было хоть одно событие, флаг
«стычка 1–24 погибших» — в 88,4 %. В Candidate за 2026 год 34 % событий помечены как
требующие проверки (`Check dyad`, `Check deaths` и другие).

Вывод: на истории проверка вслепую идёт по выверенному GED, а в реальном времени модель
получит более шумные данные. Это не покрыто (раздел 11). Исторический GED в будущее не
подглядывает: каждое событие датировано своим днём, месячные суммы собираются из событий
этого месяца, годовые агрегаты в признаки не входят (это сторожат тесты).

### 2.2. Архив conflictforecast.org

В проекте лежит один снимок — папка `latest`, скачанная 07.11.2026. Шесть рядов: начало
(`ons`) двух видов насилия на горизонтах 3 и 12 месяцев и интенсивность. Горизонта 6 месяцев
у них нет.

- Строки: 182 страны и территории × месяц, январь 2010 — октябрь 2026.
- `fatalities_UCDP` — погибшие от **всех трёх типов насилия**; совпадает с нашей колонкой
  `deaths_best` в 100 % из 32 814 общих строк 2010–2025.
- `anyviolence` — в месяце есть хотя бы один погибший. `armedconf` — в месяце погибло
  **не меньше 0,5 человека на миллион жителей** (проверено по данным: граница проходит
  между 0,4997 и 0,5004).
- Целевая `ons_armedconf_h_target` определена только для месяцев без конфликта и равна 1, если
  конфликт будет хотя бы в одном из следующих h месяцев. «Без конфликта» — это один текущий
  месяц, а не 12 тихих месяцев, как у нас: Украина в марте 2014-го у них снова «под риском».
- Прогнозы четырёх моделей (`naive`, `hist` — история насилия, `text` — темы новостей,
  `all` — всё вместе) есть для каждой строки с 2010 года. Целевая известна по июль 2026
  (3 месяца) и октябрь 2025 (12 месяцев).

Три оговорки для сравнения «яблоко к яблоку»:

1. Их событие другое: любое насилие, включая банды и теракты, с порогом на душу населения. У
   Мексики или Гондураса это «конфликт», у нас — нет.
2. Признаки их строки включают её собственный месяц. Мы считаем с лагом в 1 месяц, поэтому
   свои прогнозы показываем в двух вариантах: с лагом и без (`_l0`).
3. В файле лежат прогнозы сегодняшней версии их модели на сегодняшних данных. По описанию
   авторов они получены вслепую (переобучение по мере движения во времени), но проверить это
   по одному снимку нельзя, архивных версий в открытом доступе нет.

## 3. Панель и целевые

Месячная панель — та же, что в боевом `panel.py` (сверено: до декабря 2025 колонки совпадают
ячейка в ячейку), но продлённая событиями Candidate до сентября 2026: 178 стран, 77 454
страна-месяца. Боевой файл `panel_country_month.parquet` не тронут, новая панель лежит в
`war_month_panel.parquet`.

- **Месяц войны** — `state_war25` месячной панели: ≥ 25 погибших за месяц в государственном
  конфликте на своей территории или у соседа, где страна — сторона. Негосударственное (тип 2)
  и одностороннее (тип 3) насилие в целевую не входит. Таких месяцев 8 083 (10,7 %).
- **Мирная страна** — 12 месяцев подряд без месяца войны. **Начало** — первый месяц войны
  после этого; с 1989 по 2025 год начал 307.
- **Метка горизонта h** — была ли война хотя бы в одном из месяцев m+1 … m+h.
- Две модели, как в годовой: начало учится на мирных строках, продолжение — на остальных.
  Строка получает модель по тому, что о стране **известно** (события по m − 1, стороны — по
  прошлогоднему списку), а оценивается начало на строках, мирных **по факту**. Известное и
  фактическое состояние расходятся в 2,1 % строк.
- Обучение: модель для месяцев года T учится один раз, на метках, известных к концу декабря
  T−1. Метка известна, когда окно закрылось и вышли события его последнего месяца:
  t + h + 1 ≤ декабрь T−1.
- Оценка: 1996–2025, строки, чьё окно целиком лежит в выверенном GED.

| Горизонт | Мирных страна-месяцев | С началом войны в окне | Разных начал |
| --- | --- | --- | --- |
| 3 месяца | 49 989 | 607 (1,21 %) | 210 |
| 6 месяцев | 49 592 | 1 142 (2,30 %) | 210 |
| 12 месяцев | 48 794 | 2 010 (4,12 %) | 210 |

Одно начало войны попадает в окно нескольких соседних строк одной страны, поэтому
положительных строк больше, чем начал. Интервалы считаются блоками по годам и эту зависимость
учитывают.

## 4. Предвестники «дым до огня»

Признаки (`month_features.py`), все — по событиям не позже месяца m − 1:

- **свои стычки ниже порога**: погибшие в государственных столкновениях за 3 / 12 / 24 месяца,
  число событий, число месяцев с 1–24 погибшими, ускорение (последние 3 месяца против темпа
  предыдущих 9);
- **негосударственное и одностороннее насилие**: погибшие и события за 3 и 12 месяцев;
- **у соседей** (общая граница по суше или море до 12 миль; у соседа считаются только бои на
  его территории): субпороговые погибшие, доля соседей со стычками, негосударственное и
  одностороннее насилие, ускорение;
- **столкновения с другими государствами** (набор `live`, раздел 6.1).

Среди мирных страна-месяцев стычки 1–24 погибших за последний год были у 9,3 %,
негосударственное насилие — у 7,1 %, одностороннее — у 12,3 %.

Наборы: `dry` — эталон, из истории которого убраны субпороговые погибшие; `smoke_nb` — эталон

Что видно:

1. **Дым добавляет на 3 и 6 месяцах, на 12 — нет.** На мире прирост маленький (+0,012), на

   ближайших месяцев, а не следующего года.

   +0,056 [+0,034; +0,079] на тихих ≥ 5 лет (3 месяца). То есть гипотеза «дым до огня» верна,
   просто боевая модель пользовалась ею с самого начала.
3. **Постсоветские — ноль, на 12 месяцах минус** (−0,013 [−0,024; −0,003]). 22 начала —
   слишком мало, чтобы что-то утверждать, но прироста там точно нет.

### 6.1. Живая хроника столкновений

Из событий UCDP (`live_pairs.py`) собраны четыре вида столкновений пары A ← B:

- **прямые** — обе стороны события правительства: Индия–Пакистан, Киргизия–Таджикистан
  (65 событий с 2014 года), Иран–Израиль (с 2017-го), Россия–Украина (с 2014-го);
- **прокси** — событие конфликта, где A и B по разные стороны по списку сторон ACD, но само
  событие не «правительство против правительства»: Армения ↔ Азербайджан (в UCDP Карабах —
  это Азербайджан против Арцаха, Армения — помогающая сторона), Россия ↔ Украина в Донбассе
  2014–2021;
- **вторжения** — на территории A воюет правительство B, а правительство A в событии не
  участвует: Израиль в Ливане («Хезболла»), Турция в Ираке;
- то же зеркально.

Признаки пары на строке года T (события по ноябрь T — декабрьский файл к 1 января не вышел):
`live_years15` (в скольких из 15 последних лет были столкновения — прямой аналог `mid_force`),
`live_ld3` (погибшие за 3 года), `live_ev12` (события за год). Вселенная пар расширена
«проявленной враждой»: добавлены пары со столкновениями за последние 15 лет (в 2025 году —

### 6.3. Калибровка внешнего канала

Сырая свёртка `s = 1 − ∏(1 − p_пары)` считает коалиционную войну столько раз, сколько в ней
противников. Правка: внутри обучения (метки ≤ T) диадные прогнозы сворачиваются по странам, и
на страновой целевой «начало войны с государством-противником» учится одномерная
логистическая поправка. В тест не подглядываем.

## 10. Тесты

`uv run pytest` — 52 проверки, все зелёные; `pyflakes` чист. Новые:

- `test_available_from_war_month_features` — признаки строки месяца m не зависят от событий
  месяца m и позже, от списка сторон ACD текущего года, от структурных данных текущего года;
  контроль: без лага порча месяца m видна.
- `test_future_blindness_war_monthly_model` (3 и 12 месяцев) — прогноз в точке `as_of` не
  меняется от порчи всех событий месяца `as_of` и позже; контроль: если убрать лаг из правила
  известности метки, порча видна.
- `test_month_label_and_evaluable_sync` (3 / 6 / 12) — метка смотрит ровно в m+1 … m+h; за
  концом хроники — пропуск, а не ноль; на мирных строках положительная метка — всегда начало
  по правилу 12 тихих месяцев.
- `test_live_pairs_kinds_and_lag` — прямые столкновения, прокси и вторжения не смешиваются и
  не считаются дважды; годовой признак не видит декабрьских событий.
- `test_future_blindness_dyad_live` — диадный прогноз, сырая свёртка и откалиброванный `p_ext`
  не зависят от событий после ноября T и от страновых меток, ещё не известных к T.

**Тест поймал утечку.** При прогнозе из середины года в обучение попадали метки текущего года,
а факт «страна — сторона войны у соседа» зависит от списка сторон ACD, который выходит после
конца года. В боевом прогоне обучение всегда идёт «на декабрь», и там этого не было, но
правило известности метки дополнено: окно должно кончаться в году, за который список сторон
уже вышел. Цифры отчёта от этого не изменились.

## 11. Ловушки и что не покрыто

1. **Ревизии Candidate → GED.** На истории стоит выверенный GED. В реальном времени 5 %
   флагов «месяц войны» и 12 % флагов «стычка» будут другими (раздел 2.1). Архивных версий
   Candidate за 2020–2024 годы хватило бы на проверку, но это отдельная работа.
2. **Список сторон ACD внутри года.** Признаки берут прошлогодний список; новая сторона,
   вступившая в войну в этом году, до января не видна (Армения в сентябре 2020-го).
3. **Месячный порог 25 погибших строже годового.** Годовая `state_war25` — 25 за год,
   месячная — 25 за месяц. Вялотекущий конфликт (Донбасс 2016–2021) по годовому правилу —
   война, по месячному — череда «мирных» месяцев с редкими всплесками. Отсюда «Украина уже
   воевала» в 2022-м и 307 начал вместо 151 годового.
4. **«После 2014» завышает качество.** AUC 0,90–0,92 в этой эпохе — следствие того, что войны
   идут в недавно воевавших странах; на тихих ≥ 5 лет там всего 25 начал.
5. **Вторжения дают ложные пары.** Турция в Ираке против РПК — для диадной модели «вражда
   Турции и Ирака», хотя правительства не воюют. В прогнозе внешнего канала на 2026 год
   Турция ← Ирак на первом месте (0,31) именно поэтому.
6. **Израиль ↔ «Хезболла», ХАМАС** — по-прежнему не пара государств; Газа в UCDP кодируется
   как территория Израиля.
7. **conflictforecast — один снимок.** Что их исторические прогнозы получены вслепую, мы
   знаем со слов авторов.
8. **Население для их порога** берётся за год Y−2 (последнее известное); на границе порога
   это даёт 1,7–5,3 % расхождений с их целевой.

## 12. Развилки для Ангелины

1. **Калибровка внешнего канала — в кандидаты на 4.3?** `dy_cal` даёт тот же AUC, что
   `dy_intext`, и снимает перекос (1,19 → 1,06). Слабое место: после 2014 года прироста над
   `pitf` нет вовсе, так что это кандидат «не хуже `pitf`, чуть точнее по Brier», а не
   прорыв. Альтернатива — оставить витрину на `pitf` и диадный канал закрыть.
2. **Месячный прогноз войны — в витрину на 4.3?** Варианты: (а) добавить две колонки —
   3 и 12 месяцев, набор `smoke_nb`; (б) только 3 месяца (на 12 дым ничего не даёт, а годовой
   прогноз уже есть); (в) не добавлять. Слабое место (а) и (б): целевая другая (25 погибших в
   месяц), её придётся объяснять рядом с годовой; у воюющих стран колонка всегда около 1.
3. **Живые стычки и раздельные модели — закрыть?** Обе правки прироста не дали. Предлагаю
   оставить код как срез для сравнения (`make variants`) и в витрину не брать. Возражение:
   живая хроника — единственное, что не устареет, когда `MID` состарится ещё на пять лет;
   тогда её стоит оставить в модели «на вырост», смирившись с −0,009.
4. **Порог месячной целевой.** Сейчас 25 погибших в месяц. Альтернатива — «25 за скользящие
   12 месяцев» (ближе к годовой целевой, Донбасс тогда — непрерывная война, а февраль 2022-го
   всё равно не начало). Третий вариант — отдельная целевая эскалации (скачок в разы), чтобы
   ловить 2022 год и Тыграй. Это меняет смысл блока, поэтому не делала.
5. **Ревизии Candidate.** Проверять ли на архивных версиях 2020–2025, насколько прогноз в
   реальном времени хуже проверки на выверенных данных? Полдня работы; без этого месячный
   прогноз в витрине будет с непроверенной оговоркой.
6. **Украина-2014.** Четыре чекпоинта подряд (PITF, политика, диады, дым) она остаётся «из
   ниоткуда». Варианты: принять как предел метода на открытых данных; или в 4.3 проверить
   единственный непроверенный класс сигналов — сетевое заражение по режимным и языковым
   графам (оно в плане).

## 13. Решения, принятые по ходу

Чтобы можно было проверить и откатить:

1. Месяц войны — существующая `state_war25` месячной панели (25 погибших в месяц); «мирная» —
   12 тихих месяцев. Взято из `panel.py`, чтобы не заводить вторую целевую.
2. Лаг событий 1 месяц применён ко всем признакам месячной модели, включая состояние
   «воюет / мирная», по которому выбирается модель.
3. Оценка начала — на строках, мирных по факту, прогноз — по известному состоянию.
4. Обучение раз в год «на декабрь», как в `econ_contagion`; регуляризация выбирается внутри
   обучения по времени (последние 5 лет — проверочные).
5. Заведён «сухой» эталон `dry`, которого в задании не было: без него вклад дыма выглядел бы
   втрое меньше настоящего.
6. Оценка месячной модели — только по выверенному GED (по 2025 год); строки 2026 года
   получают прогноз, но в метрики не входят.
7. Целевая conflictforecast восстановлена по нашей панели с населением за Y−2; оценка — по их
   колонке.
8. Живая хроника: четыре вида столкновений; «вторжение» засчитывается, только если
   правительство страны места в событии не участвует.
9. Вселенная диад расширена парами с проявленной враждой (по прошлому). Оказалось не на
   пользу (раздел 6.2, пункт 3), но оставлено — иначе Израиль ↔ Иран не оценить.
10. Раздельные модели: группа с менее чем 10 началами в обучении берёт общую модель.
11. Калибровка `p_ext` — логистическая поправка на прогнозах «на себе» внутри обучения, а не
    на прошлых прогнозах вслепую (второй способ проверен, хуже).
12. Годовые живые признаки считаются по ноябрь T (декабрьский файл выходит 20 января). Старые
    годовые признаки боевой модели по-прежнему берут весь год T — их не трогала.
13. Боевые файлы (`panel_country_month.parquet`, `risk_2025_26.csv`, `forecasts/`) не менялись.
14. В `ROADMAP.md` записаны твои решения по 4.1 и заметки к отбору 4.3.

## 14. Как воспроизвести

```
uv run python -m seldon download ucdp_candidate
uv run python -m seldon month_features
uv run python -m seldon model_month
uv run python -m seldon model_month cf
uv run python -m seldon dyads_live
uv run python -m seldon model_hist pitf_smoke logit state_war25
uv run python -m seldon model_hist pitf_live logit state_war25
uv run python -m seldon compare_war live
uv run python -m seldon compare_month
```

Всё это входит в `make variants` (нужны готовые `make all`, `dyads` и `model_dyad`). Месячная
модель считается минуту, бутстрэп срезов — около семи, годовое сравнение — около десяти.

Новые модули: `sources/ucdp.py` (Candidate), `domains/conflict/live_pairs.py`,
`month_features.py`, `model_month.py`, `model_dyad_live.py`, `evaluation/compare_month.py`;
дополнены `compare_war.py` (`live`), `model_hist.py` (наборы `pitf_smoke`, `pitf_live`),
`core/temporal.py` (лаг `ucdp_events`).
