# Селдон — память проекта

Личный проект Ангелины: модель, которая прогнозирует войны и экономические кризисы.
Глобальная модель с углублением в постсоветское пространство. Вдохновлено психоисторией
из «Основания» Азимова, но цель приземлённая: работающий прогноз, проверенный «вслепую».

Карта существующих систем и данных (ресёрч): https://claude.ai/artifact/NUKDLvVMxefGmZnL8GnzQy
Репозиторий: https://github.com/unicat-42/seldon · доска: https://github.com/users/unicat-42/projects/1

## Принципы проекта

1. **Сначала самое простое.** Базовая модель → повторение чужих моделей → только потом своё.
   Усложняем, только если простое проигрывает. (На соревновании ViEWS 2023/24 13 команд
   проиграли простой базовой модели организаторов.)
2. **Честная проверка.** Только прогнозы «вслепую» (`out-of-sample`): модель учится на прошлом
   и предсказывает период, которого не видела. Никаких утечек будущего в признаки.
3. **Прогноз — это вероятность, а не «да/нет».** События редкие, ложных тревог будет много,
   и это нормально.
4. **Всё воспроизводимо.** Скачивание данных — скриптом, а не руками. Данные в git не кладём.

## Как работать с Ангелиной

- Ангелина — продакт-менеджер, по образованию физик. Код не пишет: его пишет Клавдия,
  Ангелина задаёт вопросы и принимает решения.
- Общение по-русски. Английские термины, названия файлов и библиотек — в бэктиках.
- Объяснять, что делаем и зачем, простыми словами. Любую метрику или аббревиатуру
  расшифровывать при первом упоминании.
- Дату брать только из команды `date` в начале сессии, не выводить из файлов.
- Работать по шагам самостоятельно, не спрашивать подтверждения на мелочи. Останавливаться,
  если не хватает данных или доступа (регистрация, ключ API — не обходить), или если развилка
  меняет смысл проекта.
- Если источник требует регистрации или ключа (например, ACLED) — остановиться и сказать,
  что сделать Ангелине.
- В конце сессии: что готово, что не получилось, какой следующий шаг.

## Окружение

- Python 3.12 через `uv`. Запуск: `uv run python ...`, ноутбуки: `uv run jupyter lab`.
- Библиотеки — в `pyproject.toml`, ставятся `uv sync`.

## Структура

```
data/raw/        сырые скачанные файлы (не в git)
data/processed/  обработанные таблицы (не в git)
notebooks/       ноутбуки разведки и экспериментов
src/seldon/      код: загрузчики данных, признаки, модели
reports/         отчёты и итоги
```

Загрузка данных: `uv run python -m seldon.download <источник>` (см. `src/seldon/download.py`).

## Дорожная карта

- Неделя 1 (сделано 07.11.2026, см. `reports/2026-11-07-session-1.md`): окружение, структура,
  загрузка UCDP, PITF, conflictforecast, разведка данных. Главные находки: PITF replication
  data — выборка «случай–контроль», а не панель; UCDP кодирует Грузию 2008 и Карабах 2020
  как внутренние конфликты с участием других государств, не как межгосударственные.
- Неделя 1–2, шаг 1 (сделано 07.11.2026, см. `reports/2026-11-07-session-2-baseline.md`):
  панель страна×год/месяц по UCDP (`panel.py`), базовые модели `last`/`decay`/`base_rate`
  с проверкой вслепую 1996–2024 (`baseline.py`). `decay`: Brier 0.060, AUC 0.95, на онсетах
  AUC 0.80 — но Грузию 2008, Украину 2014 и Карабах 2020 не видит.
- Неделя 1–2, шаг 2 (сделано 07.11.2026, см. `reports/2026-11-07-session-3-pitf.md`):
  модель PITF повторена точно (`pitf.py`, условный логит, совпадение с опубликованными
  вероятностями до 0,0003). Ловушка: `clogit` даёт вероятности только внутри страты —
  к новым случаям модель надо переобучать на панели. Данные PITF кончаются 2003 годом.
  Дальше: сравнение с conflictforecast, целевая «страна — сторона конфликта», сборка
  признаков PITF (Polity5/V-Dem, WDI) на нашей панели.
- Неделя 3–4: повторение модели Банка Англии (Bluwstein и др.) по их коду с GitHub,
  добавление постсоветских стран из Global Macro Database, проверка на девальвациях
  1998, 2008, 2014–2015.
